## Code

Inline code: `const greeting = "hello"`;

A fenced code block:

```javascript
function fibonacci(n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}

console.log(fibonacci(10)); // 55
```

Another one in Python:

```python
def greet(name):
    return f"Hello, {name}!"

print(greet("World"))
```
